# Online Coaching Management System

## Implemented Features

### Backend (Spring Boot)
- Authentication & Authorization (JWT)
- User Management (Admin, Teacher, Student)
- Course Management
- Lecture Management
- Quiz System
- Assignment System
- Payment Integration (Razorpay)
- File Upload
- Messaging System
- Discussion Forums
- Live Classes
- Calendar Events
- Attendance Tracking
- Student Progress Tracking
- Results & Grading
- Certificates
- Analytics & Reporting
- Support Tickets
- Audit Logging
- AI Chat Integration
- Push Notifications

### Frontend (React)
- User Authentication (Login, Register, Password Reset)
- Admin Dashboard
- Teacher Dashboard
- Student Dashboard
- Course Catalog & Details
- Course Creation & Management
- Lecture Player
- Quiz Taking & Submission
- Assignment Submission
- Payment Processing
- Messaging Interface
- Discussion Forums
- Calendar Integration
- Analytics Charts
- Settings Management
- Support Ticket System
- AI Chat Interface

### Database
- MySQL with Flyway migrations
